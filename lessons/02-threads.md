# Урок 2 — резьба под печать

Статус: план теста (2026-09-16).

## Симптом

Болт ⌀35.7×45 (Thread1: ISO M36×4, 6g, Modeled) и две гайки 45×18 (вычитание болта из цилиндра + Offset Faces −0.2 и ~−0.4 мм). Гайка с бо́льшим зазором накручивается, но болтается; с меньшим — тугая. Печать с `seam aligned` — капли шва на витках.

## Что решено

- Подход верный: наружная резьба Thread (Modeled), внутренняя — вычитанием + Offset Faces на гранях витков. Зазор подбирается печатью, а не расчётом.
- «Плотность» резьбе даёт **упор** (фланец/буртик, в который гайка затягивается), а не нулевой зазор.

## Best practices — резьба под FDM (Fusion)

- Наружная: **Thread → Modeled** (без Modeled это текстура, не геометрия). Внутренняя: Thread на отверстии (Modeled) или вычитание болта + Offset Faces по граням витков.
- Шаг: для 0.4 сопла / 0.2 слоя — **≥ 2 мм**, лучше 3–4 (M36×4 — отлично); ISO 60° печатается стоя без поддержек (боковой свес 30°).
- Ориентация: ось резьбы **вертикально** у обеих деталей; горизонтальная резьба — ступеньки на витках.
- Зазор — не расчёт, а константа принтера: подбирается лестницей 0.15–0.30 мм на гранях витков; одно значение на пластик, записать в CONTEXT.md.
- Плотность даёт **упор** (буртик/дно), а не зазор; без упора любая резьба болтается.
- Фаска 1×45° на входе у обеих деталей — лёгкое наживление, нет закусывания первого витка.
- Шов: scarf (Contour) обязательно — капли `aligned`-шва садятся на рабочую грань витка и клинят.
- Не масштабировать деталь ради посадки — только Offset Faces витков: масштаб ломает шаг.

## Тест: лестница зазоров

Короткий болт 10–12 мм + 4 гайки с зазором по граням 0.15 / 0.20 / 0.25 / 0.30, печать после теста 1 (scarf). Выбрать самый малый зазор, при котором гайка идёт рукой без закусывания → записать в CONTEXT.md как константу принтера для PLA.
