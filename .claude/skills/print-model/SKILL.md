# Подготовить модель к печати

Дима даёт модель — агент возвращает готовый проект на SD-карте и одну фразу, что нажать. Инструкций вида «найди поле X» не давать: настройки выставляет агент, собирая вариант проекта.

Железо и пластик — `CONTEXT.md`. Решения, на которые опирается этот скилл, — `docs/adr/0003-slicing-resolution.md`, урок `lessons/04-makerworld-presets.md`.

## Шаги

### 1. Забрать модель

| Источник | Что делать |
| --- | --- |
| MakerWorld «Open in Bambu Studio», чужой 3MF | `bbs_project.py retarget` — принтер, филамент, процесс на наши; авторские правки процесса сохраняются автоматически. На сайте сперва проверить Select Profile: есть профиль под A1 mini — брать его. Советы автора по бриму и поддержкам — с поправкой на его принтер: у P2S/X1/P1 стол неподвижен, у A1 mini ездит по Y. |
| STL | загрузить как есть, все три пресета выставить самому |
| Fusion | просить **STL-экспорт**, не STEP — см. `references/slicing-quality.md`, раздел «Меш» |

### 2. Оценить модель

- Габариты против стола 180 × 180 × 180. Не влезает — спросить про масштаб или разрезку, не решать молча.
- Меш: круглое должно быть круглым (мелкие треугольники на скруглениях). Большой счётчик граней сам по себе не проблема — предупреждение Studio «Simplify model» для нарезки игнорируется.
- Где на модели будут проблемы: нависания круче ~45°, мосты, тонкие торчащие элементы, большая плоская подошва (коробление).
- **Внутренний пол, полка, крышка внутри стенок** (коробки, вазы, планшеты) → на этой высоте будет «линия пола» — сразу `references/clean-prints.md` §1: в первую очередь фаска по рёбрам пола в дизайне, дальше порядок стенок и скорости.
- Узкие места, тонкие стенки, мелкие перемычки → в предпросмотре смотреть gap fill и ретракты: точки — это будущая грязь, §2 (Arachne / ширина 0.5).
- **Пологие скаты** (рёбра, спины, купола лежащей органики) → ступеньки: контуры слоёв как горизонтали на карте. `tools/mesh_slopes.py <проект>` сразу, по мешу — проверка 15 в `references/forecast.md`. Лечит только слой тоньше на этих высотах (шаг 3); скорость и температура тут ни при чём.
- Несколько деталей на столе → `print_sequence = by object`, ставить близко.
- **Полое дно или стоячая узкая деталь** (свистки, флейты, фигурки на пятачке): пятно первого слоя — по расходу первого слоя, не по габариту; меньше трети подошвы при высоте > 40 мм или h/ширина > 3.5 → брим `outer_only` 5 мм сразу (проверка 10). «Brim not needed» у автора с P2S/X1 не переносится на A1 mini — стол ездит по Y (свисток 19.09 оторвало на 96 %).

### 3. Выбрать три пресета

Принтер **A1 mini 0.4** → филамент **свой откалиброванный** (таблица в `CONTEXT.md`) → процесс **`… @BBL A1M` + правки автора, если модель чужая**. Чужие филамент и машину не тащить никогда.

Слой под задачу:

| Задача | Процесс |
| --- | --- |
| черновик, функциональная деталь | `0.20mm Standard @BBL A1M` |
| видовая органика (фигурки, скульптура) | `0.12mm Fine @BBL A1M` |
| плоские вертикальные стенки, где видна рябь | `… High Quality` (наружная стенка 60 вместо 200 мм/с) |

Слой — первый выбор, не окончательный: прогноз (шаг 5) может вернуть сюда один раз. Тонкие верхушки, гребни, острия — проверка 7 даёт > 25 % слоёв быстрее 6 с — **слой на шаг толще** (утка: 0.12 → 36 %, 0.16 → 29 %, 0.20 → 23 %) или башня-охладитель рядом. Ступеньки (проверка 15) — **слой тоньше** на отмеченных высотах: переменная высота слоя 0.08 там, штатный слой на остальном; делается **модификатором диапазона высот**: `bbs_project.py ranges <in> <out> <объект по порядку в 3dmodel.model> <z_lo> <z_hi> layer_height=0.08` — 0.08 только на отмеченной полосе, штатный слой на остальном (Моаи 19.09: макушка 82–106 мм, 6 ч 31 вместо 7 ч 56 на сплошном 0.12). Профиль `layer_heights_profile.txt` CLI игнорирует — им не пользоваться. Поддержки под моделью: зазор по Z ≥ 0.2 (у `0.12mm Fine` базовый 0.12 — один слой, прикипает; ставить 0.24–0.3), по XY 0.6–0.8, если стволы идут вплотную к деталям.

Ширина линии — инструмент, а не рычаг качества: ýже «для качества» не делать (качество стенки даёт слой), но 0.5 на стенках допустимо и быстрее, верх чуть ýже — чище (`clean-prints.md` §8).

### 4. Наложить настройки качества

Всегда:
- `--set resolution=0.004 --set slice_closing_radius=0.01`, `enable_arc_fitting` оставить 1 (ADR-0003);
- `--set precise_outer_wall=1`, генератор стенок classic, число стенок пресетное (ADR-0004): третья стенка — рычаг проверки 5 против валика на высотах сплошных слоёв, но гладкий борт с ней выглядит хуже (Benchy v1 против v3 — Дима выбрал v1); Arachne портит мелочи — только по явной просьбе; авторские стенки чужого проекта не трогать;
- `--set reduce_crossing_wall=1 --set max_travel_detour_distance=300` — сопло не таскает каплю через наружную стенку;
- паттерн верха под форму: круглое → `top_surface_pattern=concentric`, остальное — monotonic.

Дальше — по симптомам и геометрии: `references/clean-prints.md` (линия пола, крошечные экструзии, порядок стенок, блеск, модификаторы, время) и `references/slicing-quality.md` (меш, разрешение).

### 5. Проверить и дать прогноз

1. `bbs_current.py <файл>` — пресеты те, отличий от базы ровно столько, сколько задумано. Расхождение — искать в `different_settings_to_system`, а не гадать.
2. CLI-нарезка `--slice 0 --export-3mf` — без ошибок; из шапки G-code и `result.json`: время, слоёв, граммы.
3. **Прогноз** — все 16 проверок из `references/forecast.md`: 15 по мешу (`tools/mesh_slopes.py`, ещё на шаге 2), остальные по нарезанному G-code (`tools/gcode_features.py`, `tools/gcode_layers.py`; 16 — `tools/gcode_airtravel.py`, только для деталей с функциональной полостью: свисток, канал, направляющая). Каждое срабатывание — тяжесть (**стоп / заметно / мелочь**), место, причина, что лечит. Шаг закончен, когда все 16 отмечены и блок «Прогноз:» составлен — в том числе «стоп-факторов нет».
4. **Рычаги** — пункт «заметно» с рычагом-настройкой (таблица «Рычаги» в `forecast.md`) агент не оставляет советом: собирает вариант `--set`, режет, сравнивает `tools/gcode_compare.py`, берёт вариант, если время не выросло больше чем на 15 % и другие проверки не ухудшились; иначе даёт оба с разницей. Один рычаг на вариант. Если прогноз упирается в выбор слоя или поддержек (проверки 7, 8, 15) — вернуться на шаг 3 один раз, пересобрать, прогноз заново; в блоке сказать, что изменено и почему.

### 6. Отдать — одна кнопка в Studio

Дима жмёт **Print plate** в Bambu Studio, Studio шлёт на принтер через облако (Developer Mode не нужен). Для этого файл должен открыться как *нарезанный* (Preview, Print активна), а не как проект:

1. `bbs_project.py gcode3mf <cli-export>.gcode.3mf <name>.gcode.3mf` — убирает геометрию; Studio считает нарезанным только файл без меша.
2. Studio должна **уже работать** (одно окно): `pgrep -fl MacOS/BambuStudio`; нет — `open -a BambuStudio`, дождаться окна (`winctl windows`). Файл на холодный старт подвешивает Studio без окна.
3. `open -a BambuStudio <name>.gcode.3mf` — уходит в открытое окно (в `BambuStudio.conf` `app.single_instance = true`; если снова плодятся окна — закрыть все, вернуть true). Проверить снимком окна: Preview + зелёная Print plate + наши пресеты в шапке.
4. Сказать: блок «Прогноз:» из шага 5, затем «в окне Studio `<name>` — Print plate → Send», какой пластик заправить; кадром с камеры убедиться, что стол пуст и **пластина стоит**. При **стоп** — вместо «Print plate» варианты выбора; кнопку не предлагать, пока Дима не выбрал.

Запасной путь: `bbl_printer.py upload` на SD и старт с экрана принтера/Handy. Удалённый старт с Мака прошивка не пускает — `start_print` врёт `True`, судить по `status`.

### 7. Записать, если есть что

Проблемная или эталонная печать → `prints/YYYY-MM-DD-<name>/` (`settings-diff.txt`, фото, заметка) — с разделом **«Прогноз vs факт»**: что предсказано, что вышло; промах порога → поправить `references/forecast.md`. Вывод, переживающий эту модель → урок или ADR. Разовое «как работает X» — оставить в чате.

## Справочники

- `references/clean-prints.md` — главный: симптом → причина → ключи. Линия пола, крошечные экструзии, пересечение стенок, порядок стенок, пятна блеска, паттерны, модификаторы, ширина линии, первый слой и стол, время. С нашими текущими значениями.
- `references/slicing-quality.md` — разрешение нарезки, arc fitting, качество меша; замеры на нашем принтере.
- `references/filament-calibration.md` — порядок и правила калибровки новой катушки.
- `references/forecast.md` — 16 проверок прогноза (по мешу и по нарезанному G-code), пороги, тяжесть, рычаги-варианты, формат блока «Прогноз:».
