# Образец пластика

Образец показывает пластик таким, каким он выходит в обычных деталях, поэтому процесс не выбирается:
`models/filament-swatch/swatch.py` режет на `0.20mm Standard` с пакетом качества. Формат карточки и почему он такой —
`models/filament-swatch/README.md`.

## 1. Спросить

Одним сообщением (AskUserQuestion), с рекомендацией в каждом вопросе:

- **Какая катушка заправлена.** Учёта пластика нет, поэтому ответ знает только Дима. Варианты — цвета из таблицы
  калиброванных филаментов в `CONTEXT.md`.
- **Что написать.** Рекомендация — бренд / материал / цвет: «SUNLU / PLA Matte / Oak».
- **Какая плита на столе.** Рекомендация — текстурированная; для PETG только она.

Что Дима уже назвал в просьбе, не спрашивай. Готово, когда известны строки текста, плита и пресет
филамента Orca
(`~/Library/Application Support/OrcaSlicer/user/default/filament/`). Для некалиброванного пластика бери ближайший
системный пресет и говори в ответе «образец на некалиброванном пресете»: карточка покажет его цвет, но не то, как он
будет печататься после калибровки.

## 2. Меш карточки

`models/filament-swatch/bambu-card.stl` в git не лежит (лицензия Bambu), поэтому в свежем worktree его нет. Скопируй
его из основного чекаута: `/Users/rudnikdmitriy/dev/3d-print-learning/models/filament-swatch/bambu-card.stl`. Если
нет и там — README, раздел «Первый запуск».

## 3. Собрать и нарезать

```
models/filament-swatch/swatch.py "SUNLU" "PLA Matte" "Oak" --filament "SUNLU Matte @BBL A1M" --bed textured
```

Первая строка встаёт справа от защёлки, остальные ниже. `--bed textured|smooth` — плита на принтере. Готово, когда
в выводе:
- кегль всех строк не меньше 3.5 мм — иначе скрипт предупреждает, и самую длинную строку надо сократить;
- 10 слоёв, `M1002` десятками (настоящий стартовый блок Bambu), около 11 минут и 1.2 г;
- в последней строке плита, которая стоит на принтере: `Textured PEI Plate` или `High Temp Plate` (так Orca называет
  гладкую).

## 4. Отдать

Файл — `models/filament-swatch/out/<имя>/<имя>.gcode.3mf`. Открой его `open -a OrcaSlicer <файл>` и проверь
`pgrep -lx OrcaSlicer`: процесс должен быть один, иначе файл ушёл в новый экземпляр, а тот принтер не видит. Кнопки
Slice plate → Print plate → Send жмёт Дима.

Прямая просьба запустить («запусти», «сразу напечатаем») — добавь `--send` к команде шага 3: скрипт загрузит файл и
стартует печать без калибровки потока, с выравниванием стола. Файл с буквами мельче 3.5 мм или без стартового блока
Bambu он не отправит. В worktree сначала скопируй `.printer.json` из основного чекаута. Приём
подтверди через 20 с: `tools/bbl_printer.py status` показывает этот файл и 10 слоёв.
