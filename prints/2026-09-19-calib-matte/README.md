# 2026-09-19 — калибровка SUNLU PLA Matte (Grey / Oak), база — системный `SUNLU PLA Matte @BBL A1M`

База отличается от PLA+: flow 0.98, **MVS 21** (у PLA+ 12), плотность 1.3, диапазон 205–245 °C, этикетка 200–230 °C. Матовый — другая рецептура (наполнитель), поэтому свой пресет (ADR-0002). Порядок для второй линейки: башня → Flow fine на выбранной T → MVS → пресет `SUNLU PLA Matte @BBL A1M` в `profiles/user/`.

- `base-matte.3mf` — прошлая башня, перенесённая `retarget` на A1 mini / 0.20mm Standard / SUNLU PLA Matte / Textured PEI; от неё собираются все столы.
- `temp-tower-235-200.3mf` — башня 8 блоков 235 → 200 °C (`bbs_calib.py temp … 235 200`); STL мастера — все 35 блоков 350 → 180, нужный диапазон вырезает `tools/mesh_cut.py`. Подписи отлиты на задней грани, **нижний блок 235**, ступень −5 °C каждые 10 мм (M104 на z = 10.2, 20.2 … 70.2). `temp-tower-235-200.gcode.3mf` — CLI-нарезка без геометрии для Studio (Print plate → Send): 400 слоёв, 65 мин, 15 г.
- Чтение башни: по каждому блоку — стенки (чистота, блеск), нависания (ступенчатый козырёк), мост, стрингинг между колонками, чёткость подписи. Берём **верхнюю** температуру из диапазона, где всё приемлемо (правило ADR-0002: выше — прочнее слои и выше MVS).
- `flow-fine.3mf` — Flow Rate fine на выбранной T: 10 блоков −9…0 % поверх базы **1.02** (так диапазон 0.93 → 1.02 накрывает 0.98 с двух сторон; подпись блока ≠ flow ratio, таблица ниже).
- `mvs-4-30.3mf` / `mvs-4-30.gcode.3mf` — MVS-цилиндр 4 → 30 мм³/с на выбранных T и flow; чтение как 16.09: высота первого дефекта h → поток = 4 + 26·(h − 0.4)/59.6, в пресет −10…20 %.
