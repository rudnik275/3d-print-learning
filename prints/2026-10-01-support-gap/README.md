# Зазор поддержек SUNLU PLA — 01.10

Семь полок 18 × 16 мм на высоте 8 мм, у каждой свой `support_top_z_distance`, значение выдавлено на полке. Сзади деревья `T0.2` / `T0.4`, спереди обычные `0.10 … 0.30`. 0.20 Standard, от стола, xy 0.8, интерфейс 2 слоя / 0.5. CLI: 41 мин + 6, 14.6 г. `build.py` пересобирает стол и меряет реальный зазор каждого образца по G-code.

**Результат:** все поддержки отпали почти сами; лучший низ — обычные 0.10, дерево 0.2 шершавее, дерево 0.4 провисает. Почему деревьев только два — они кладут зазор на сетку слоёв (0.1–0.3 при слое 0.2 режутся как 0.2). Вывод — `lessons/07-supports-bridges-top.md`, ADR-0007.
