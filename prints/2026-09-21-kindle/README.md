## Прогноз vs факт

- **Промах прогноза, стоивший печати.** Ни одна из 16 проверок не увидела клипсу, начинающуюся в воздухе: проверка 4 смотрит долю нависающих стенок и молчит, когда поддержки включены, а блокировщик убирает их молча — ни один признак в G-code не меняется. Добавлена проверка `scripts/gcode_unsupported.py` (в плагине): сравнивает материал слоя с материалом под ним и делит найденное на `bridging` / `cantilever` / `over infill`. На клипсе она даёт `cantilever run y 9.1 mm`, на всех остальных столах — чисто.
- **Ложная тревога инструмента.** `gcode_features` показывал у решётки «мост 102 мм» — это одна непрерывная экструзия через тридцать опор, реальные пролёты 1.0–1.6 мм. Метрика «самая длинная экструзия» — верхняя граница, не пролёт; новая проверка меряет настоящие участки.
- **Вторая ложная тревога.** Первая версия новой проверки нашла «консоль 124.9 мм» на губах щёчек и коробки — на деле они нормально подпёрты, просто интерфейс лежит на три слоя ниже из-за `support_top_z_distance`. Глубина просмотра теперь считается из шапки G-code: `ceil(зазор / слой) + 1`.
- `support_top_z_distance 0.25` на PETG — снимаются ли деревья с губ чисто, проверяется этой ночью.
