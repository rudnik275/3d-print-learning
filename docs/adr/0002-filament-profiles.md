# ADR-0002. Профили филамента: один на линейку, результат калибровки — пресет в Studio

Дата: 2026-09-16. Статус: принято.

## Решение

- Итог калибровки каждого пластика — **пользовательский пресет филамента** в Bambu Studio (`profiles/user/*.json`, `inherits` от ближайшего системного: `SUNLU PLA+ @BBL A1M`, `SUNLU PLA Matte @BBL A1M`, `Generic PETG @BBL A1M`), импортируется через Import Configs, синхронизируется в облако Bambu. Дима выбирает его в списке филаментов; всё остальное — как обычно.
- В пресет входят только филаментные ключи: `nozzle_temperature` (+ initial layer), `filament_flow_ratio`, `filament_max_volumetric_speed`, при необходимости вентилятор и bed temp. Настройки процесса (scarf, стенки) — отдельно, в пресетах процесса.
- **Один профиль на линейку, не на цвет**: пигмент меняет расход в пределах ~1 % — ниже полезного разрешения. `SUNLU PLA` (Bone White, Beige) — один пресет; `SUNLU PLA Matte` (Grey, Oak) — отдельный, матовый — другая рецептура (наполнитель, ниже MVS, обычно другой расход/температура); `SUNLU PETG` — отдельный.
- Порядок калибровки линейки: Flow Rate coarse (только для первой линейки; для следующих — сразу fine от базового значения) → башня температур → Flow Rate fine на выбранной температуре → Max Volumetric Speed → пресет. PA не калибруется: A1 mini делает flow dynamics автоматически перед печатью.

## Последствия

- Имена пресетов: `SUNLU PLA @BBL A1M`, `SUNLU PLA Matte @BBL A1M`, `SUNLU PETG @BBL A1M` — `@BBL A1M` оставлять, Studio по нему фильтрует совместимость.
- Значения фиксируются в `CONTEXT.md` (таблица «Калиброванные филаменты») с датой — при смене катушки/производителя перекалибровать.
