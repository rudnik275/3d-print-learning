# ADR-0008 — Gridfinity: два пресета-близнеца по пластику, Arachne, одно ядро для бинов и сетки

Дата: 2026-10-13. Статус: принято, пресеты записаны в Studio (`.info` → облако) и собраны в Orca через `tools/orca_presets.py`.

## Контекст

К 13.10 Gridfinity жил на трёх пресетах процесса, выросших по отдельности: `gridfinity` (PLA, бины), `gridfinity - GRID` (базовые плиты) и `Gridfinity PETG 0.20 A1 mini`. Сверка показала рассогласование, а не разные задачи: в `gridfinity` не было `resolution 0.004` при остальном пакете качества, в PETG-пресете пакета не было совсем, включая обход стенок при переездах, из-за чего PETG тянет нитки через проём бина; слоновья нога нигде не стояла, хотя первый слой бина это самая узкая часть ножки с фаской 0.8 мм; в `gridfinity` лежали ключи ironing от старых опытов без включённого ironing.

Разница между бином и плитой по процессу сводится к узору заполнения, рисунку верха и числу стенок, и её можно убрать. Разница по пластику убрать нельзя: мосты и нависания SUNLU PLA (ADR-0007) живут в пресете процесса, а для PETG они не калибровались.

## Решение

Gridfinity это **два пресета с одинаковым ядром**, на бины и на сетку: `Gridfinity PLA 0.20 A1 mini` и `Gridfinity PETG 0.20 A1 mini`. Старые `gridfinity` и `gridfinity - GRID` удалены (`.info` → `sync_info = delete`).

| Что | Значение | Зачем |
| --- | --- | --- |
| База | `0.20mm Standard @BBL A1M` | единица Gridfinity 7 мм делится на слой 0.2 ровно |
| Стенки | 3, генератор **Arachne** | губа бина сходит до 0.7 мм, ножка и губа толще двух линий; Classic печатает их линией 0.42 плюс gap fill, Arachne одной дорожкой переменной ширины. Решение без A/B-теста, по замерам 13.10 на ведре продувки (стенка 1.2 мм: gap fill 12.7 % → 0) и стакане MaxFlow (стенка 0.9 мм) |
| Заполнение | gyroid 10 % | бин это стенки, заполнение почти не работает |
| Низ / верх | 4 / 5 слоёв | дно бина держит вес, верх губы ровный |
| Рисунок верха | concentric | выбор Димы по сетке 09.2026, на дне бина ложится так же |
| Слоновья нога | 0.15 | ножка 0.8 мм садится в базу как задумано |
| Шов | `back`; в Orca плюс scarf `external` с условием по углу и `wipe_on_loops` (добавляет конвертер) | линия сзади, сглажена |
| Пакет качества | `resolution 0.004`, `slice_closing_radius 0.01`, `precise_outer_wall`, `reduce_crossing_wall` с обходом 300 мм, без башни | ADR-0003 / ADR-0004; обход стенок режет нитки PETG через проём |
| Мосты, только PLA | `bridge_flow 1.6`, `bridge_speed 10`, нависания 2/4 и 3/4 по 10 мм/с; в Orca внутренние мосты и нависания возвращены к обычной нити (×0.625) | ADR-0007 |
| Мосты, PETG | не переопределены; в Orca thick bridges при потоке 1.0, внутренние 50 мм/с | без калибровки не выдумывать |

Нарезка Gridfinity агентом берёт эти пресеты по пластику, а не системный `0.20mm Standard`.

## Последствия

- Слой строго 0.20: 0.24 и 0.28 ломают деление высоты на 7 мм и огрубляют фаски ножки и губы (три слоя вместо четырёх на фаске 0.8 мм). Сопло 0.6 возможно только с генератором, где стенка кратна 0.62; профили MakerWorld считаны под 0.42.
- Первая печать бина на новом ядре это и проверка Arachne на губе; если губа выйдет хуже, чем на Classic, это отдельное решение с цифрами, а не откат по памяти.
- Копии: `profiles/user/` (Studio), `profiles/orca/process/` (Orca). Правки только через цепочку Studio-JSON → `tools/orca_presets.py` → перезапуск Orca.
