# ADR-0004 — Стенки по умолчанию: classic, три стенки, precise wall

Дата: 2026-09-18. Статус: принято.

## Контекст

Пакет `print-model` до этого дня менял поверх системного `0.20mm Standard @BBL A1M` только разрешение, замыкание контура и объезды стенок (ADR-0003). Число стенок оставалось пресетным — две. Две печати показали один и тот же дефект: горизонтальный валик по наружной стенке на высотах, где внутри детали идут сплошные слои (палуба Benchy на 8–8.6 мм, полки коробки урока 1). Сплошное заполнение перекрывает стенки на 15 % (`infill_wall_overlap`) и выдавливает две тонкие стенки наружу.

Проверено одной переменной на Benchy 18.09 (`prints/2026-09-18-benchy/`):

- v1 — две стенки: валик на высоте палубы виден и прощупывается.
- v2 — Arachne: щелевое заполнение ушло в ноль, но буквы, планки крыши, кромка трубы и перемычки стали хуже, стрингинга больше. Широкие дорожки переменной ширины на потоке, калиброванном под 0.42.
- v3 — classic, три стенки: валик не читается, крыша и труба чище, надпись чётче. Цена: +6 % времени, +9 % пластика.

Коробка 17.09 (три стенки) дала тот же эффект: стенки заметно ровнее печати 16.09 с двумя.

## Решение

В пакет «всегда» скилла `print-model` входят `wall_loops = 3`, `precise_outer_wall = 1`, генератор стенок classic. Arachne — только по явной просьбе и как единственная переменная эксперимента.

## Последствия

- Время печати +5–10 %, пластик +7–10 % на деталях с большой долей стенок; на органике с поддержками разница меньше.
- Проверка 5 прогноза (линия пола) с этим пакетом ожидается как «мелочь»; если валик остался — рычаг дальше только в дизайне (фаска по кромкам полки).
- Проверка 6 (крошечные экструзии) лечится шириной стенки 0.5 или `filter_out_gap_fill`, не Arachne.
- Чужие проекты (`retarget`) авторское число стенок сохраняют, если оно больше трёх; если автор оставил две — пакет ставит три.
