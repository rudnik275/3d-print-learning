# ADR-0006. Скилл print-model уезжает в публичный плагин `bambu-print-model`; здесь остаётся опыт

Дата: 2026-09-21. Статус: принято.

## Контекст

Знакомые просят скилл `print-model`. В этом репо он сросся с личным: имя владельца, даты и модели в правилах, катушки SUNLU в примерах, A1 mini в числах (стол 180, левые 20 мм, клиренс 25), macOS-автоматика (клики UIDrive, ScreenGrab, winctl — разрешения привязаны к бинарникам), принтер по LAN, камера, снимок машинного G-code именно этого принтера. Отдать это другому нельзя, а держать две версии вручную — разойдутся за месяц.

Грилл 21.09 зафиксировал: главная ценность — накопленный опыт печати (какие настройки под какой тип модели, как резать сборку на столы, где печать сломается и что лечит), а не обвязка. Обвязку под все случаи жизни не строить: пользователь решает своё окружение со своим Claude.

## Решение

- Публичный плагин Claude Code `rudnik275/bambu-print-model` (MIT, английский): один скилл `print-model` + `references/` (симптомы → ключи, 16 проверок прогноза, качество нарезки, калибровка филамента, плейбук по типам моделей) + `scripts/` (переносимые инструменты: сборка и правка проектов, `retarget`, блокировщик поддержек, STEP → STL, калибровочные столы, разбор G-code и меша). Любой принтер Bambu, любая платформа; размер стола и клиренс читаются из пресета машины; снимок машинного G-code пользователь делает сам (`bbs_project.py snapshot`) в `~/.print-model/`.
- Перед печатью ровно два вопроса: какой филамент из откалиброванных и что важнее (быстро / качественно / прочно) — как пожелание, а не пакет настроек. Без мастера первого запуска, без вопросов по деталям, без ограничений по AMS. Без откалиброванного филамента — предупредить и предложить калибровку, печать не запрещать.
- Не входят в плагин: клики в Studio, камера, `bbl_printer.py`, Fusion MCP, персональные правила («запускай», стол — зона Димы). Они остаются в `CLAUDE.md` этого репо.
- Этот репо — первый пользователь плагина: локальный `.claude/skills/print-model/` удалён, скилл приходит из плагина. `prints/`, `lessons/`, ADR, `CONTEXT.md`, память остаются здесь.
- Поток знаний: урок из печати → правило в плагин (английский, без дат и имён, с числами) при закрытии сессии; запись о печати остаётся здесь. Порог прогноза, который промахнулся, правится в плагине, не в личной копии.

## Последствия

- Скилл теперь один, обновления знакомым — `/plugin marketplace update`.
- Личное окружение (клики, LAN, камера) живёт только в `CLAUDE.md` репо и не мешает чужим.
- Цена: правки скилла идут через второй репо и PR; при закрытии сессии добавляется шаг «дистилляция».
- Копии переносимых инструментов в `tools/` этого репо пока остаются — от них зависят `prints/*/build.py`; канонические версии в плагине, правки вносить туда и копировать сюда, пока записи не перенаправлены.
