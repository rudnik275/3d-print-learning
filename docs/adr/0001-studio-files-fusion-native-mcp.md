# ADR-0001. Bambu Studio читаем файлами, Fusion — нативным MCP

Дата: 2026-09-16. Статус: принято.

## Контекст

Нужно «видеть» настройки Bambu Studio и Fusion из сессии агента. У Studio нет MCP; у Fusion есть встроенный сервер (127.0.0.1:27182) и сторонний add-in Faust (`fusion360`, :9876), который часто не поднят.

## Решение

- Studio: состояние берётся из её файлов — автосейв текущего проекта (`$TMPDIR/bamboo_model/…/.3mf`), сохранённые `.3mf`, пресеты `user/` + `system/BBL` с раскрытием `inherits`, `BambuStudio.conf`. Скриншот окна — только когда важно, что нарисовано на экране.
- Изменения в Studio вносит Дима через UI по названным ключам; пачку — импортом JSON-пресета. Файлы `user/` не редактируются напрямую.
- Fusion: нативный MCP через `tools/fmcp.py`; add-in Faust — запасной.
- MCP к самому принтеру (телеметрия/камера по MQTT) не заводится, пока нет задачи, которой не хватает файлов Studio и телефона.

## Последствия

- Настройки видны полностью и без прав macOS; скриншот требует разрешения «Запись экрана» процессу `claude`.
- Каждая проблемная печать фиксируется как сохранённый проект в `prints/` — иначе автосейв перезапишется следующим проектом.
